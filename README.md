# Remdom25 — вариант 2: макет по референсам

Второй статический макет сайта ООО «РСК» / Remdom25, собранный по шести референсам из папки `redesign/`.
Светлая «архитектурная» подача: тонкая типографика, волосяные линейки, много воздуха, олива и коричневые акценты.

Открыть: **`index.html`**. Всё локально, без сервера.

## 3. Дизайн-система (снята с референсов)

- **Фон:** `#F4F1EB`, полосы `#EDE9DF` и `#EAE6DC`, тёмный блок и подвал `#282B25`.
- **Текст:** `#282B25`, второстепенный `#6E7368`, третичный `#8C9086`.
- **Акценты:** олива `#8A7B5C` (кнопки), коричневый `#A87545` (стрелки, номера).
- **Шрифт:** Inter 300/400/500, заголовки — 300 с трекингом −0.02em.
- **Сетка:** подпись раздела слева (250 px), заголовок со сдвигом, контент на всю ширину; линейки 1 px вместо карточек и теней.
- **Кнопки:** прямоугольные, заливка оливой или обводка; стрелка ↗ у всех действий.
- **Подписи разделов:** «01 / ПРОЕКТЫ ДОМОВ» — 9–10 px, капс, трекинг .12em.

Ключевые блоки повторяют референсы: hero «Ваше место под солнцем» с фото и карточкой-подписью, три цифры, карточки проектов без рамок с двумя ценами, тёмный блок «Надёжность — это то, что стоит за фасадом», видео Rutube с подписью и ссылкой на плеер, блок эскроу с панелью, шесть шагов, форма на полосе, подвал с крупным логотипом и четырьмя колонками.
